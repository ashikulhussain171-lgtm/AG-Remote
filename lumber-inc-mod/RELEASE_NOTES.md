Lumber Inc 1.13.3 (com.lumber.inc, arm64-v8a) — currency mod

- Gold (cash), Diamond, BizPoint and VillageCoin never drop below 999,999,999.
- Spending works normally but the balance is clamped back to 999,999,999, so "NOT ENOUGH DIAMOND" no longer appears for costs below that.
- Reputation and Gear are unchanged.

Install: uninstall the original game first (signature differs), then install `Lumber.Inc_1.13.3_mod.apks` with SAI (Split APKs Installer) or any .apks installer.
